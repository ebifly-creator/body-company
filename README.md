# ボディ改造カンパニー

自宅で静かにできる筋トレを、1か月続けるための記録アプリです。
スマホやPCのホーム画面に追加して使えます。

公開ページ: https://ebifly-creator.github.io/body-company/

## ファイル

- `index.html` … アプリ本体
- `sw.js` … オフラインで開くための設定
- `manifest.webmanifest` … ホーム画面に追加するための設定
- `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `apple-touch-icon.png` … アイコン

記録はこのリポジトリではなく、あなたのブラウザ（同期を設定した場合は、別の非公開リポジトリ）に保存されます。
